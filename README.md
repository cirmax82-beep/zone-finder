# 환경 지구·지역 현황

https://zone.biogrideia.com

시군구를 고르면 보호구역과 지정 지역을 환경영향평가서 지역개황의 「환경 관련 지구·지역 지정 현황」 표 형식으로 정리해 보여주는 정적 사이트입니다.

## 자료 출처

- 보호구역 경계·면적: KDPA 한국보호지역 통합DB (국립공원공단·기후에너지환경부), 2025년판. 2026년 7월 행정구역과 겹쳐 시군구별 면적을 계산했습니다(지도 계산값).
- 천연기념물·명승: 국가유산청 국가유산 검색 OpenAPI (지정 해제 제외)
- 보호수: 산림청 「2025년 말 보호수 지정현황」 (https://tree.biogrideia.com 정리본)
- 대기관리권역·저황유·고체연료·청정연료 지역: 국가법령정보센터의 시행령 별표 원문
- 행정경계: vuski/admdongkor (통계청 행정동 경계 기반, CC BY 4.0), 2026-07-01판

지정 현황은 수시로 바뀌고 KDPA 자료는 실제 고시와 다를 수 있으므로, 평가서에 쓰기 전 해당 기관의 최신 고시로 확인하세요.
